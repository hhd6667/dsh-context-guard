# dsh-context-guard

[English](README.md) · **简体中文**

[DeepSeek Harness (DSH)](https://www.npmjs.com/package/@deepseek-ai/dsh) 的纯浏览器端插件：在大上下文会话切换到小窗口模型前进行保护，并可在模型额度或限流失败时自动切换到用户指定的备用模型。

- 插件界面跟随 DSH 当前语言（中文/英文）；自动续接提示也会使用当前语言。
- 无需构建步骤、React、原生模块、凭据或后台进程。
- 宿主端只负责挂载，所有行为都在 DSH Web 客户端中运行。
- 在 Windows/Node 24 上的 DSH Web profile `0.2.0-rc.2` 开发并验证；不保证其他版本兼容。

## 功能

### 手动切换模型时的上下文保护

在大窗口模型上积累了较长上下文后，直接切换到小窗口模型通常会在“选择模型”时成功，却在发送下一条消息时因提示词过长而失败。

插件监听当前会话的 `modelSelection` 和 `contextPressure` 投影。当当前用量达到目标模型安全阈值（默认 70%）时，会：

1. 立即回退到原模型；
2. 显示不透明、适配明暗主题的对话框，提供三个选项：
   - **先压缩再切换**：执行 `/compact`，等待上下文压力下降后再切换；
   - **仍然切换**：接受风险，立即切换；
   - **保持原模型**：继续使用原模型。

所有程序化模型切换都会回读投影、在会话繁忙时重试并进行确认，避免 RPC 失败或竞争导致模型静默地停在错误选择上。关闭或刷新页面时，也会保持原模型，而不是让有风险的新选择生效。

### 额度/限流时自动切换

输入框工具栏中的 **自动切换** 按钮会打开当前会话的设置。你可以：

- 为每个对话单独启用或关闭自动切换；
- 从实时模型目录中选择候选模型；
- 使用上移/下移按钮调整优先级，最上方优先级最高；
- 对内置表中没有的模型手动填写上下文窗口（tokens）。

当实时轮次以 `QUOTA`、`ACCOUNT_QUOTA`、`RATE_LIMIT`、HTTP 429，或明确的余额/额度不足消息终止时，插件会：

1. 等待当前轮次停止运行；
2. 按顺序选择下一个候选，并跳过本轮已经失败的模型；
3. 检查当前上下文是否低于候选窗口的 70%；
4. 必要时先执行 `/compact`，并确认上下文确实下降；
5. 切换并从投影验证新模型；
6. 仅发送一次排队续接消息，要求模型从已有进度继续，不重复已完成的工作。

自动切换默认关闭。设置按会话保存在浏览器的 `localStorage` 中。

## 上下文窗口

浏览器模型目录本身不携带每模型 `contextWindow`。插件按以下顺序解析：

1. **你在候选行里手填的值**（优先级最高；留空则使用自动检测值）。
2. **DSH 自己模型设置里已经解析出的窗口**：通过 `remote.settings.describe()` 只读获取一次，包含 provider 配置里明确的 `contextWindow` 和适配器默认值；打开弹窗时会再刷新。
3. **内置表**：[`dsh/client.js`](dsh/client.js) 顶部的 `DEFAULTS`，按精确 `provider/model`、模型 ID、保守子串匹配依次查找。
4. 都解析不到时，窗口视为**未知**。

检测到的值会直接显示出来：候选行里作为占位符（如 `262144 自动获取`），模型目录每一行后面显示（如 `· 262K`），所以不用先填就知道会用多少。

模型无法识别时：

- 手动切换保护**不会阻止切换**，避免对未知的 1M 模型误报；
- 自动切换**不会把它当作安全候选**，除非你手填真实上下文窗口。

手填值必须是模型的**上下文窗口**，不要填最大输出长度。内置示例包括：`deepseek-flash` 为 1,000,000 tokens，`ark-code-latest` 为 262,144 tokens。

### 切换后的圆环上限

DSH 的上下文圆环是用实测压力除以「会话最近一次真实请求」（`request/context`）里记录的上限。切换模型不会写入这条记录，只改变已保存的选择，所以切换刚完成时，圆环仍显示**上一个模型**的上限——即使切换其实已经成功。

当圆环和当前选中的模型不一致时，插件会在 **自动切换** 按钮旁显示一个小标签，给出当前真正生效的上限和占用比例（例如 `42% · 262K`；超过上限时变红并显示 `118% · 超过 262K`）。悬停可以看到两边的具体数值。下一条消息发出、圆环自己更新后，标签会自动消失。

因为两个模型上限相同时这个不一致只存在一瞬，而且任何一次请求都会立刻把它抹平，所以**每次切换模型后**标签也会以中性配色停留约 12 秒，用来确认新的上限；之后自动隐藏。看不到标签就说明圆环和当前模型已经一致。

## 安装

本包是一个 Web profile bundle。以下方式是从仓库副本进行本地 profile 安装；未来 DSH 可能提供其他插件安装机制。

1. 将包复制到 Web profile，例如：

   ```text
   ~/.dsh/profiles/web/vendor/dsh-context-guard
   ```

2. 在 `~/.dsh/profiles/web/package.json` 中添加依赖：

   ```jsonc
   {
     "dependencies": {
       "dsh-context-guard": "file:vendor/dsh-context-guard"
     }
   }
   ```

3. 在同一文件的 bundle 列表中注册，并放在基础包和 Web 应用之后：

   ```jsonc
   {
     "dsh": {
       "profile": {
         "bundles": [
           "@deepseek-ai/dsh-base",
           "@deepseek-ai/dsh-web-app",
           "dsh-context-guard"
         ]
       }
     }
   }
   ```

4. 重启 `dsh web`，然后刷新浏览器页面。

`cordis.patch.yml` 会挂载空的宿主端，使加载器同时提供 `dsh/client.js`（通过 `dsh.client` 声明）。

## 使用

- 像平时一样切换模型；只有当前上下文接近或超过目标阈值时才会出现警告。
- 点击输入框工具栏的 **自动切换**，为当前显示的对话配置候选模型。
- 当前会话启用后，按钮为绿色；关闭时恢复普通外观。
- 只要行里已经显示检测到的值（如 `262144 自动获取` 或 `· 262K`），“窗口 tokens”就可以留空；只有显示“未知”或对该 provider 检测值不对时才需要手填。
- 只监听当前打开的对话，离开页面或会话会取消正在进行的自动操作。
- 切换后请以 **自动切换** 旁的标签为准，而不是圆环：圆环要等下一次请求才会更新上限。

## 限制

- 浏览器端没有 API 能重放底层失败请求；自动切换后发送的是一条新的排队续接消息，模型仍可能重复部分推理。对非幂等的外部操作请自行核对。
- 自动切换必须等到终止的 `turn/end` 错误；如果 provider 配置为无限重试，可能永远不会出现该事件。
- 普通认证、网络、取消和不相关服务器错误不会触发切换。
- 如果已耗尽的模型无法执行 `/compact`，插件不会把超长提示强行发给更小的候选模型，而是继续尝试更安全的候选，最后停止。
- 页面关闭后没有 service worker 或后台进程继续保护。
- `localStorage` 按浏览器/profile 隔离，不会在浏览器、设备或无痕会话之间同步。
- 浏览器插件无法写入会话记录，因此无法直接修正圆环的上限，只能在其不一致时显示正确值。
- Provider 推出新模型时，需要维护本地上下文窗口表。

## 卸载

1. 从 `dsh.profile.bundles` 中移除 `dsh-context-guard`。
2. 从 `dependencies` 中移除该包。
3. 删除 profile 中的包目录。
4. 重启 `dsh web` 并刷新页面。

清除站点数据会删除按会话保存的自动切换设置。
